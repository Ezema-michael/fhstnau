# FHST Journal and Scientific Conference source

This repository contains the web application and its D1 schema migrations. For an editor to administer a new deployment, set `FHST_EDITOR_USER_ID` or `FHST_EDITOR_EMAIL` as a server-side runtime variable for the authenticated user. Do not commit real values. Configure D1, R2 and authentication for the deployment environment. The existing hosted database and uploaded manuscripts are separate and are not included here.
